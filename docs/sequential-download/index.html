How to enable sequential download in Transmission

Sequential download makes Transmission fetch pieces in order instead of randomly. It is useful for media files that you want to start watching while they are still downloading. The option is stored on the daemon, so it works for local and remote sessions alike.

Requirement: Transmission 4.1 or newer (RPC 18). On older daemons the checkbox stays disabled — this is a limitation of the daemon, not of the client.

The steps below use transmissionGUI, a desktop GUI for Transmission.

Enable it for a single torrent

  1. Add the torrent. Open Torrent → Add torrent (or drop a .torrent file onto the window), choose the destination and files, and tick Sequential download in the options row.
  2. Or change an existing torrent. Select it in the list and open Properties → General. The Sequential download checkbox applies the change to the daemon immediately when you confirm the dialog.

Batch editing also works: select several torrents, open Properties, set Sequential download to Enable or Disable, and confirm.

Enable it automatically by file extension

  1. Open Application options with Ctrl+F9 and go to the Sequential download tab.
  2. Turn on Enable automatically for files with these extensions.
  3. List the extensions, one per line, for example mkv, mp4, iso.
  4. Confirm with OK. New torrents that contain a single matching file are added with sequential download already enabled.

The automatic rule only applies to torrents that contain one file. For multi-file torrents use the checkbox in the Add torrent dialog.

Troubleshooting

SymptomReason and fix
The checkbox is greyed out The daemon is older than Transmission 4.1 (RPC 18). Update the daemon and reconnect.
Extension rule is ignored The torrent contains several files. Enable the checkbox manually in the Add torrent dialog.
Files still download out of order Pieces that were already downloaded are kept. Sequential download affects the pieces that are still missing.
Setting disappears after reconnecting to another daemon The option belongs to the torrent on that specific daemon. Each daemon keeps its own state.

Frequently asked questions

Which Transmission version supports sequential download?

Transmission 4.1 and newer (RPC 18). In older versions the checkbox is disabled and the RPC field is not accepted by the daemon.

Does sequential download apply to torrents that are already downloading?

Yes, the setting can be changed at any time in Properties → General, but pieces that were already downloaded keep their state. Only the remaining pieces are fetched in order.

Why is the automatic extension rule not applied to my torrent?

The automatic rule only works for torrents that contain a single file. Multi-file torrents need the checkbox enabled manually in the Add torrent dialog.

Do I have to use transmissionGUI?

No. Sequential download is stored on the daemon, so any client that exposes the setting can change it. transmissionGUI makes it available in a native desktop window together with the rest of the torrent management.
