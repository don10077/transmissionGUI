Клиент Transmission, а не обёртка над веб-интерфейсом

transmissionGUI — нативное приложение на C++23 / Qt 6 для битторент-демона Transmission. Оно работает напрямую с JSON-RPC API демона, поддерживает Windows, Linux и macOS и не встраивает веб-интерфейс Transmission.

Удалённое управление

Подключение по HTTP или HTTPS, профили, сопоставление путей, прокси и клиентские сертификаты. Переключение между несколькими демонами в пару кликов.

Последовательная загрузка

Файлы скачиваются по порядку, а не случайными кусками. Автоматические правила по расширению или включение для отдельного торрента.

Полное управление торрентами

Запуск, остановка, очередь, приоритеты, метки, переименование, проверка и удаление. Файлы, пиры, трекеры и статистика сессии.

Что можно делать

  • Сортировать и искать торренты, фильтровать по статусу, группировать по папке, метке или трекеру.
  • Добавлять .torrent файлы, magnet-ссылки и URL, выбирать файлы и лимит пиров, перетаскивать файлы в окно или следить за локальной папкой.
  • Менять свойства пакетно, переносить несколько торрентов одним запросом, экспортировать и импортировать настройки.
  • Пользоваться значком в трее, горячими клавишами, настраиваемыми цветами и столбцами.
  • Обновлять базу GeoIP, разрешать имена пиров, обновлять blocklist и проверять новые версии.

Последовательная загрузка в Transmission

Transmission 4.1+ (RPC 18) умеет скачивать торрент по порядку. В transmissionGUI это включается двумя способами:

  1. Автоматически для выбранных файлов. Откройте Параметры приложения → Последовательная загрузка, включите «Включать автоматически для файлов с расширениями» и укажите нужные расширения.
  2. Для одного торрента. Поставьте галочку Последовательная загрузка в диалоге добавления торрента или откройте Свойства → General и включите её там.

Полная инструкция: как включить последовательную загрузку в Transmission

Работает с Transmission 2.x, 3.x, 4.0 и 4.1+

ДемонРежим RPC
Transmission 2.x / 3.x / 4.0.xLegacy JSON-RPC
Transmission 4.1+JSON-RPC 2.0, определяется автоматически

Последовательная загрузка требует Transmission 4.1 (RPC 18). Переименование меток — Transmission 4.0 (RPC 16).

Вопросы и ответы

Что такое transmissionGUI?

transmissionGUI — бесплатный GUI для Transmission с открытым исходным кодом для Windows, Linux и macOS. Он подключается к демону Transmission по JSON-RPC и управляет торрентами в нативном окне.

Как включить последовательную загрузку в Transmission?

Откройте Параметры приложения → Последовательная загрузка, чтобы включить автоматические правила для выбранных расширений файлов, или поставьте галочку Последовательная загрузка в диалоге добавления торрента либо в Свойства → General для одного торрента. Нужен демон Transmission 4.1 или новее (RPC 18).

Какие версии Transmission поддерживаются?

Transmission 2.x, 3.x и 4.0.x поддерживаются через legacy JSON-RPC API. Для Transmission 4.1+ режим JSON-RPC 2.0 определяется автоматически.

Нужен ли браузер для transmissionGUI?

Нет. transmissionGUI — самостоятельное приложение на Qt. Оно не встраивает веб-интерфейс Transmission и не требует браузера.
