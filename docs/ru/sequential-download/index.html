Как включить последовательную загрузку в Transmission

При последовательной (линейной) загрузке Transmission скачивает части торрента по порядку. Это удобно для видео и других файлов, которые хочется открыть, пока загрузка ещё идёт. Настройка хранится на демоне и работает при локальном и удалённом подключении.

Требование: Transmission 4.1 или новее (RPC 18). На более старых демонах галочка остаётся недоступной — это ограничение демона, а не клиента.

Для шагов ниже понадобится transmissionGUI, графический клиент для Transmission («Трансмишн»).

Включить для одного торрента

  1. Добавьте торрент. Откройте Торрент → Добавить торрент (или перетащите файл .torrent в окно), выберите папку и файлы и поставьте галочку Последовательная загрузка в строке параметров.
  2. Или измените существующий. Выберите его в списке и откройте Свойства → Общие. Галочка Последовательная загрузка применит изменение к демону сразу после подтверждения диалога.

Пакетное изменение тоже работает: выделите несколько торрентов, откройте свойства, задайте для Последовательная загрузка значение Включить или Выключить и подтвердите.

Включить автоматически по расширению файлов

  1. Откройте Параметры приложения сочетанием Ctrl+F9 и перейдите на вкладку Последовательное скачивание.
  2. Включите пункт Включать автоматически для файлов с расширениями.
  3. Перечислите расширения по одному в строке, например mkv, mp4, iso.
  4. Подтвердите кнопкой OK. Новые торренты из одного подходящего файла будут добавляться с уже включённой последовательной загрузкой.

Автоматическое правило применяется только к торрентам из одного файла. Для многофайловых используйте галочку в диалоге добавления торрента.

Если что-то не работает

СимптомПричина и решение
Галочка недоступна Демон старше Transmission 4.1 (RPC 18). Обновите демон и переподключитесь.
Правило по расширению игнорируется Торрент содержит несколько файлов. Включите галочку вручную в диалоге добавления.
Файлы всё равно качаются не по порядку Уже скачанные куски сохраняются. Последовательная загрузка влияет только на оставшиеся куски.
Настройка пропадает после подключения к другому демону Параметр принадлежит торренту на конкретном демоне. Каждый демон хранит своё состояние.

Вопросы и ответы

В какой версии Transmission появилась последовательная загрузка?

В Transmission 4.1 и новее (RPC 18). В более старых версиях галочка недоступна, а демон не принимает соответствующее поле RPC.

Можно ли включить последовательную загрузку для уже качающегося торрента?

Да, настройку можно изменить в любой момент в Свойства → Общие, но уже скачанные куски сохраняются. По порядку загружаются только оставшиеся.

Почему автоматическое правило по расширению не сработало?

Автоматическое правило работает только для торрентов из одного файла. Для многофайловых торрентов галочку нужно ставить вручную в диалоге добавления.

Обязательно ли использовать transmissionGUI?

Нет. Настройка хранится на демоне, поэтому её может изменить любой клиент, который её поддерживает. transmissionGUI просто предоставляет её в нативном окне вместе с остальным управлением торрентами.
