A Transmission client, not just a web UI wrapper

transmissionGUI is a native C++23 / Qt 6 application for the Transmission BitTorrent daemon. It speaks the daemon's JSON-RPC API directly, works on Windows, Linux and macOS, and does not embed the Transmission web interface.

Remote control

Connect over HTTP or HTTPS, use profiles, path mapping, proxies and client certificates. Switch between several daemons in a couple of clicks.

Sequential download

Download files in order instead of random pieces. Configure automatic rules by extension or enable it per torrent.

Full torrent management

Start, stop, queue, prioritize, label, rename, verify and remove torrents. Inspect files, peers, trackers and session statistics.

What you can do

  • Sort and search torrents, filter by status, group by folder, label or tracker.
  • Add .torrent files, magnet links and URLs, choose files and peer limits, drop files onto the window or watch a local folder.
  • Edit properties in batch, move several torrents with one request, export settings and import them back.
  • Use the tray icon, keyboard shortcuts, configurable colors and column layout.
  • Update the GeoIP database, resolve peer hostnames, update the blocklist and check for new releases.

Sequential download in Transmission

Transmission 4.1+ (RPC 18) can download a torrent in order. In transmissionGUI you can enable it in two ways:

  1. Automatically for selected files. Open Application options → Sequential download, turn on “Enable automatically for files with these extensions” and list the extensions you need.
  2. For a single torrent. Tick Sequential download in the Add torrent dialog, or open Properties → General and enable it there.

Install

Download the package for your platform from GitHub Releases.

  • Windows x64 — run the -setup.exe installer, or extract the portable ZIP and run transmissiongui.exe.
  • Linux — DEB package for Ubuntu and compatible distributions.
  • macOS — DMG image with the application bundle.

Prefer building from source? The project uses CMake presets; the README lists the MSYS2, Linux and macOS steps.

Frequently asked questions

What is transmissionGUI?

transmissionGUI is a free, open-source Transmission GUI for Windows, Linux and macOS. It connects to the Transmission daemon over JSON-RPC and manages torrents in a native desktop window.

How do I enable sequential download in Transmission?

Open Application options → Sequential download to enable automatic rules for selected file extensions, or tick Sequential download in the Add torrent dialog or in Properties → General for one torrent. The daemon must be Transmission 4.1 or newer (RPC 18).

Which Transmission versions are supported?

Transmission 2.x, 3.x and 4.0.x are supported through the legacy JSON-RPC API. Transmission 4.1+ is detected automatically and uses JSON-RPC 2.0.

Does transmissionGUI need a web browser?

No. transmissionGUI is a standalone Qt application. It does not embed the Transmission web interface and does not require a browser.

Is transmissionGUI free?

Yes. The application is distributed under GPL-3.0. Download a package from GitHub Releases or build it from source.
