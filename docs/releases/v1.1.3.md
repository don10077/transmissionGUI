## Fixes

- Replace updated torrents even when existing files have changed sizes or the file and folder list has changed.
- Preserve the old download directory, root folder or file name, and local display name when replacing a torrent. Apply the old root name before verifying existing data.
- Carry over existing file priorities and skipped files, and keep the old entry when replacement is cancelled or renaming fails.
- Show the percentage of matching data for each file as soon as its verification finishes, while other files may still be verifying.
- Check translation freshness and theme color tokens locally before compilation using the same checks as Windows CI. Add `build.cmd ci --no-pause` for a Release build with warnings as errors and tests.
- Synchronize the Russian translation catalogue and support local source checks in Windows PowerShell with an inherited PowerShell module path.

## Replacement behavior

Transmission creates a new entry for the updated info hash and removes the old entry without deleting its data after confirmation. Upload statistics and ratio are not transferred. When downloading starts, changed files at the same paths can be overwritten by the new torrent; replacement does not keep a separate playable copy of the previous versions.
