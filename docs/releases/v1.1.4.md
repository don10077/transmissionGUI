## Changes

- Download updates from the application and verify the package against the release's SHA-256 checksum. On Windows x64 the application closes before starting the installer. On Apple Silicon macOS it opens the disk image, and on Linux amd64 it passes the downloaded Debian package to the desktop's registered handler.
- Hide stale torrent data when the daemon is unavailable. Show the connection error and a countdown when automatic reconnect is enabled, and restore the list after receiving fresh data.
- Fit initial and restored column widths to their translated headers so titles stay readable at larger font sizes.
- Set the main text color separately for light and dark themes. Preview text and progress bar colors while editing, and restore the previous colors on cancel.
